Date: 2026-11-06

## Fixture and method

`app/src/test/java/com/example/SignalEnginePythonParityTest.kt` feeds exactly 60 complete OHLCV candles into `SignalEngine.analyse` for `EUR/USD`, `M15`, with a fixed timestamp and quote. The final 35 candles are identical to the strategy-specific rows generated by Python `_strategy_rows(strategy, count=35)`. Twenty-five earlier trend candles are prefixed only to meet the Kotlin engine's minimum 60-candle input requirement. Candle timestamps retain the Python fixture's one-minute cadence. The Kotlin test uses no higher-timeframe candles and no instrument specification; those input limitations are visible in the results.

The Python reference values below were obtained by evaluating the same 60-candle lists with `evaluate_strategy(validate(rows), strategy_id=..., symbol="EUR/USD", timeframe="M15")`. Python candidates remain non-executable. The canonical 35-candle goldens are asserted in `bridge/test_strategy_parity.py`.
