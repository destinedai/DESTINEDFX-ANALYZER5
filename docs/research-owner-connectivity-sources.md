# Owner connectivity research sources

Captured 2026-11-06.

- MetaTrader 5 Python `initialize` documentation: https://www.mql5.com/en/docs/python_metatrader5/mt5initialize_py
  - `initialize()` can locate or launch a terminal, or accept an explicit terminal path, login, password, server, timeout, and portable flag.
  - It returns true only when the Python module connects successfully to the terminal. It does not replace EA heartbeat verification.
- MetaTrader 5 Python `login` documentation: https://www.mql5.com/en/docs/python_metatrader5/mt5login_py
  - `login(login, password, server, timeout)` authenticates the selected account and returns true or false.
  - Passwords must not be printed or persisted by the doctor.
- Tailscale pricing: https://tailscale.com/pricing
  - Personal is $0 for up to six users, with unlimited user devices and 50 tagged resources included.
  - Standard is $8 per user per month; Premium is $18 per user per month; Enterprise is custom.
  - The official page says Personal is for home and non-commercial use.
- Tailscale plan downgrade guidance: https://tailscale.com/docs/account/manage-plans/downgrade-plan
  - The Personal plan is not intended for commercial use.
- Kamatera Windows VPS information: https://www.kamatera.com/cloud-vps/windows-vps-hosting/
  - Windows VPS provides an isolated Windows environment, RDP access requires an additional license, and Windows Server licensing can be included or supplied by the customer.
  - The page directs users to the pricing calculator rather than publishing a fixed all-in monthly price in the extracted content.
- IONOS VPS pricing: https://www.ionos.com/servers/vps
  - VPS hosting is advertised starting at $2/month, taxes may apply.
  - Windows Server 2022 or 2025 is available, and Plesk is listed as a $6/month add-on.
  - The page states customers may use the service for commercial purposes.

Use these as dated references only. Prices and plan terms can change, so the owner must confirm the checkout price and licensing before purchase. No paid service was purchased or enabled.
