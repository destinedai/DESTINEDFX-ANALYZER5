# MetaQuotes platform facts used by the terminal integration

- MetaTrader 5 for Android is described as a mobile trading application that connects to a broker's server and supports trading/analysis. Its feature list does not describe an MQL5 EA runtime. [MetaTrader 5 for Android](https://www.metatrader5.com/en/mobile-trading/android)
- MetaQuotes describes the MT5 platform as the execution module for trading robots; the MQL5 reference says programs are compiled into EX5 files in terminal directories and Expert Advisors are attached to opened charts. [Algorithmic Trading](https://www.metatrader5.com/en/automated-trading) [MQL5 Programs](https://www.mql5.com/en/docs/runtime)
- MQL5 `WebRequest` requires the exact server origin in the terminal's Expert Advisors allowed-URL list, runs synchronously, is limited to EAs and scripts, and cannot run in Strategy Tester. [WebRequest](https://www.mql5.com/en/docs/network/webrequest)
- `CTrade.Buy` returning true is not proof that a broker executed the order; MetaQuotes specifically requires checking `ResultRetcode()` and the deal ticket. [CTrade Buy](https://www.mql5.com/en/docs/standardlibrary/tradeclasses/ctrade/ctradebuy)
- MQL5 `OrderCalcProfit` estimates P/L for current market conditions in the account currency and can support pre-trade risk sizing. [OrderCalcProfit](https://www.mql5.com/en/docs/trading/ordercalcprofit)
- MetaQuotes documents launching Windows MT5 with `/config:<file>`. The startup INI can contain `Login`, `Server`, `Password`, `KeepPrivate`, and `[StartUp]` fields for an Expert Advisor, chart symbol, period, and `.set` parameters. This supports a managed-terminal worker in principle, but the account password is present in a transient plaintext startup file and must be handled with restrictive ACLs, encrypted host storage, cleanup, and per-account process/data isolation. [Platform Start](https://www.metatrader5.com/en/terminal/help/start_advanced/start)
- MetaQuotes documents master access as full trading access and investor access as read-only. Its virtual hosting requires the trader to rent and migrate an environment through MT5/MQL5 workflows; the service page currently lists plans at $15/month for one month, $13/month for three months, $10.83/month for six months, and $10/month for twelve months, with a 24-hour trial that automatically switches to a paid plan. That is not a server-side provisioning API for DestinedFX. [Account Authorization](https://www.metatrader5.com/en/terminal/help/startworking/authorization) [Virtual Hosting](https://www.metatrader5.com/en/terminal/help/virtual_hosting) [Current VPS Plans](https://www.mql5.com/en/vps)
- MetaQuotes says accounts requiring one-time-password authorization cannot use its virtual hosting, because autonomous operation cannot supply a manual OTP at every login. This limitation must be surfaced during onboarding if that provider-hosted option is considered. [Virtual Hosting Migration](https://www.metatrader5.com/en/terminal/help/virtual_hosting/virtual_hosting_migration)

These references support the implementation/setup constraints; they do not constitute evidence that this repository's EA has compiled or executed on a broker terminal.
