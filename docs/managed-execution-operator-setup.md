# Managed MT5 execution: operator setup required

The Android app can control an account only after a DestinedFX-operated service and MT5 terminal worker are deployed. This repository does not include cloud-provider credentials, a production HTTPS hostname, an operator worker token, a credentials-encryption key, a Windows host, or MetaEditor. Nothing here is currently deployed as a hosted trading service, and no broker login or order has been tested.

## One-time deployment actions

1. **Choose and fund a Windows hosting design.** Provision a supported Windows Server host or isolated Windows VM pool with capacity sized for the maximum concurrent user terminals. The terminal must remain running. Costs depend on provider, region, instance size, storage, backups, and number of active accounts; one terminal per user gives much stronger isolation but costs more. Do not assume this is free or use a developer workstation as production hosting.
2. **Confirm platform and broker permissions.** Install the genuine broker-specific MT5 terminal and MetaEditor on the host. Confirm with MetaQuotes and each supported broker that the proposed hosted, automated account access and terminal distribution are permitted. Some brokers require OTP/extended authentication that cannot be unattended. Investor access is read-only and must not enable the trading EA.
3. **Compile and demo-verify the EA.** Compile `mt5-ea/DestinedFXTraderEA.mq5` using MetaEditor for the intended MT5 build. Configure the terminal worker to launch the terminal with the documented startup configuration. Validate broker login, fresh heartbeat, START/STOP, an explicitly authorized demo order, SL/TP, reconciliation, and restart/revocation behavior before any live account is enabled.
4. **Deploy the HTTPS control plane.** Publish `bridge/` behind a trusted TLS endpoint with persistent database storage, backups, access logs that exclude request bodies and authorization headers, rate limits, and network isolation. Keep port 8000 private. Set `TRUSTED_PROXY_IPS` to the exact TLS ingress IP/CIDR; never use `*`, since an untrusted `X-Forwarded-Proto` must not turn plain HTTP into trusted HTTPS. Set production `BRIDGE_DB_PATH`, `CREDENTIALS_FERNET_KEY`, `WORKER_TOKEN`, and public service URL as server-side secrets. Never put the worker token or encryption key in the APK or repository.
5. **Install the managed Windows worker.** Configure it with the service URL and worker token, the terminal installation, compiled EA and capacity limits. Use per-account terminal data directories, Windows ACLs, encrypted disks, process supervision and cleanup. The worker must redact credentials, remove transient startup INI files after MT5 has consumed them, and stop new trades on stale/mismatched state.
6. **Configure and release the Android app.** Set `MT5_MANAGED_SERVICE_URL` to the deployed public HTTPS origin. Release builds now fail if the URL is blank, malformed, non-HTTPS, or an obvious placeholder. Verify credentials are sent only to that origin. Users should then need only broker login, master password and exact server once; there is no per-user API token or external-service setup.
7. **Operate leases and revocation.** Keep the Windows worker supervised and monitor failed/expired jobs. Worker leases renew during status polling and expired jobs may be reclaimed. Revocation is only marked complete after the recorded terminal process identity and owned directory cleanup are verified; missing ownership markers fail safely and require operator review. Do not report such failures as successful deprovisioning.

## Published MetaQuotes hosting alternative

MetaQuotes' current VPS page lists $15 for one month, $13 per month on a three-month plan, $10.83 per month on a six-month plan, and $10 per month on a twelve-month plan. It advertises a 24-hour trial that automatically switches to the paid plan. That offering is rented and migrated through an MT5/MQL5 account workflow; it is not a DestinedFX-controlled API for automatic server provisioning. It should not be represented as a free pooled fleet for this app. See [official plans](https://www.mql5.com/en/vps) and [MetaQuotes virtual-hosting guide](https://www.metatrader5.com/en/terminal/help/virtual_hosting).

MetaQuotes documents a desktop-terminal startup INI that can contain login, server and password and can auto-start an EA. That makes the worker technically feasible, but the password appears in a plaintext transient configuration file. Production deployment therefore requires restrictive host ACLs, encrypted storage, isolated terminal data and process directories, careful file cleanup, and operational security review. See [terminal startup configuration](https://www.metatrader5.com/en/terminal/help/start_advanced/start).
