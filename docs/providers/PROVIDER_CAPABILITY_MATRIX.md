## Normalization and provenance

The shared market models include nullable quote sides, source/provider identifiers, timestamps and candle validation. Provider adapter behavior is not completely uniform: several REST paths stamp receipt time locally, while some stream parsers preserve provider event time when parseable. Do not compare these times as if they share identical semantics. The repository caches candles by symbol/timeframe and tracks source for display; no silent source merge should be added.

## Testing evidence

Relevant test sources include `app/src/test/java/com/example/MarketDataSafetyTest.kt`, `app/src/test/java/com/example/data/calendar/EconomicCalendarProviderTest.kt`, and `app/src/test/java/com/example/data/news/ForexNewsRepositoryTest.kt`. These fixtures test local logic only. They do not measure provider quota, service availability, data latency, regional access, licensing, contract stability, or current API behavior. Run the Android tests through CI or a fully provisioned Android SDK before claiming they pass on a revision.
